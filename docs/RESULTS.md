## Автоматизация

Подготовлен сценарий CI/CD для локального Windows runner с меткой `mlops-local`: восстановление данных → обучение → проверка конкретной версии → запуск контейнера сервиса → smoke test → Production. Активация требует регистрации runner и repository variable `MLOPS_RUNNER_READY=true`.

Успех автоматического выполнения подтверждается отдельным запуском GitHub Actions. Исторические F1 и предыдущая стадия Staging сами по себе не подтверждают успешный deploy или работу CI.
